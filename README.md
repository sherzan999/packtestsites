# Прототипы сайтов для местного бизнеса

Шесть одностраничных сайтов (чистый HTML и CSS, без зависимостей) по данным карточек Яндекс Карт.

| Сайт | Город | Папка |
|---|---|---|
| Лида драйв плюс (гостиница) | Лида | `lida-drive-plus/` |
| АвтоМастерС | Гомель | `avtomasters/` |
| Юджин авто | Гомель | `yudzhin-avto/` |
| Детройт | Барановичи | `detroyt/` |
| КВН | Барановичи | `kvn/` |
| Интеравто | Мозырь | `interavto/` |

## Структура
- `index.html` — страница-хаб со ссылками на все сайты
- `<slug>/index.html` — готовые сайты
- `data/raw/*.json` — исходные данные карточек (единственный источник фактов)
- `build.py` — данные и генератор, `layout.py` — макет страниц; запуск `python3 build.py`
- `scripts/fact_check.py` — сверка цифр, адресов и телефонов в HTML с JSON
- `scripts/download_photos.py` — скачивает главные фото карточек в `assets/photos/` (локально, нужен интернет), затем `python3 build.py`
- `.github/workflows/pages.yml` — автодеплой на GitHub Pages

## Как поменять текст или цену
1. Отредактируйте нужную запись в `build.py` (список `DATA`).
2. `python3 build.py && python3 scripts/fact_check.py`
3. Закоммитьте изменения.

## Публикация на GitHub Pages
```bash
git init -b main
git add .
git commit -m "Initial commit: business site prototypes"
git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
git push -u origin main
```
Затем в репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Через минуту сайты откроются по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Важно
- Это демо-версии, а не официальные сайты организаций: на страницах указано, что по первой просьбе владельца сайт будет удалён. Перед использованием согласуйте тексты и цены с владельцами.
- Фото подключены ссылками на карточки Яндекс Карт. Для локальных копий запустите `python3 scripts/download_photos.py`. Это главное фото карточки, фильтр «От владельца» не применялся: проверьте права на использование.
- Данные получены на дату сборки и могут измениться в Яндекс Картах.
